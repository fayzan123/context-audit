# Design Context — context-audit

**Target audience:** Developers who live in AI coding tools (Claude Code, Codex, Cursor) and have accumulated instruction files they can no longer see or reason about. Skeptical, screenshot-literate, allergic to marketing gloss.

**Use cases:** Open the dashboard, understand in five seconds what their setup costs per session, what never fires, and what's flagged — then disable dead weight and re-scan. Secondary: the dashboard screenshot itself is the launch asset.

**Brand personality/tone:** **Instrument-grade.** The tool measures; it never judges. The UI should feel like a precision lab instrument — oscilloscope, flight recorder, calibrated meter — not a SaaS analytics page. Serious, exact, quietly confident. Every pixel implies "this number is correct."

**Visual identity commitments:**
- Dark-first, but tinted — a near-black with the brand hue in it, never #000. A deliberate light "bench manual" variant may follow; dark is canonical.
- One signal color, used surgically for state and warnings — calibrated, not neon, no glow. Findings severity may add a second restrained hue. Everything else is tonal.
- Numerics are the protagonist: tabular figures, aligned decimal columns, units set small. A distinctive display face for the instrument's "engraved" labels; monospace only where alignment earns it, not as ambient developer wallpaper.
- Hairline rules and engraved section labels structure the page — not card grids, not drop shadows.
- Motion: one orchestrated load — the audit "sweep" revealing rows/readouts with staggered exponential ease-out — plus state-change feedback (toggle, rescan). Transform/opacity only. Nothing bounces.
- Asymmetric layout; density is a feature. Left-aligned. The header readout is an instrument panel, not a hero-metric template.

**Hard bans (AI-slop fingerprints):** purple→blue gradients, cyan-on-dark neon, gradient text, glassmorphism/blur/glow decoration, icon-above-heading cards, identical card grids, cards inside cards, thick one-side accent borders, decorative sparklines, rounded-rect + generic drop shadow, bounce/elastic easing, Inter/Roboto/system-default typography, everything-centered layouts, uniform padding everywhere.

**Acceptance test:** if a stranger would believe "an AI made this" at first glance, it fails. The screenshot should provoke "what is that tool?"
